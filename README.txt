NEXUS ESPORTS website

Open index.html in a browser. No build step needed.
To deploy, upload this folder to Netlify, Cloudflare Pages, GitHub Pages or Vercel (static hosting).

Placeholders to replace: tournaments, teams, news, stats, contact details, social links, Privacy Policy and Terms.
Images: assets/images/esports-games-cinematic.webp is the optimized collage; the original PNG is kept alongside it.

Structure:
  index.html        - markup only
  css/style.css     - all styles
  js/main.js        - all scripts (menu, active nav, tournament filter, reveal animations)
  assets/images/    - all images
